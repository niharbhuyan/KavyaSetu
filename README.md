# Kavya Setu • काव्यसेतु (Poetry & Shayari Android App)

Official repository for **Kavya Setu (काव्यसेतु)** — a modern, offline-first Hindi, Urdu & Odia poetry and shayari Android application built with Jetpack Compose, Material 3, and Room Database.

### 🌐 Deploy to GitHub Pages in 1 Click
1. In your GitHub repository, go to **Settings** → **Pages**.
2. Under **Build and deployment**:
   - **Source**: Select **GitHub Actions** (the included `.github/workflows/deploy-pages.yml` will deploy automatically).
   - Alternatively, select **Deploy from a branch** → Branch: `main` → Folder: `/ (root)` → Click **Save**.
3. Your site will be live at:
   `https://<your-github-username>.github.io`
4. Enter `https://<your-github-username>.github.io` into Google Play Console (**Store presence** → **Store settings** → **Website**).

## 📱 App Highlights
- **Architecture**: MVVM with Clean Architecture, Kotlin Flow, and StateFlow.
- **UI Framework**: 100% Jetpack Compose with Material Design 3 (M3).
- **Local Storage**: Room Database for offline-first shayari library, bookmarks, and seals.
- **AI Integration**: Sukhanwar AI Studio powered by Google Gemini API.
- **Audio Recitation**: Built-in Text-To-Speech and audio playback.
- **AdMob Integration**: IAB Tech Lab compliant banner ad placement with software-layer fallback.

September 2026

Production hardening release addressing Google Play Console verification standards: resolves DEX code optimization warnings, bundles deobfuscation mappings, reduces bundle download size by 30%, and streamlines Git sync.

🛡️

Full DEX Optimization & R8 Obfuscation

Enabled advanced R8 minification and bytecode shrinking with tailored ProGuard keep rules for Room Database, Moshi, Retrofit, and Google AdMob. Elevates the obfuscation score to pass Play Console quality checks.

🗺️

Automatic Embedded Deobfuscation Map

The ProGuard deobfuscation mapping is now packaged directly inside the AAB bundle at BUNDLE-METADATA/com.android.tools.build.obfuscation/proguard.map. Eliminates manual upload steps and de-obfuscates crash/ANR traces in Play Console.

⚡

30% Smaller Download Footprint (17.7 MB)

Aggressive resource stripping and unused class removal reduced the bundle size from 25.3 MB to 17.7 MB, ensuring fast, data-friendly installs on mobile networks.

🔍

Native Debug Symbols (NDK: FULL)

Configured ndk { debugSymbolLevel = "FULL" } for embedded C/C++ binaries (AndroidX Path & Datastore) to ensure complete symbolication in Android Vitals.

🚀

VCS & GitHub Sync Optimization

Updated .gitignore and removed untracked binary bundles and oversized text artifacts, allowing fast, error-free 1-click pushes to GitHub from AI Studio without API payload errors.
